Custom software engineering renders
code.webp, git.webp, database.webp, interface.webp, quality.webp, modules.webp

Rendered locally with Three.js in a coordinated mint/ivory material palette.
Code, Git and quality assurance contours use Phosphor Icons, retrieved through
Local Design Tools / Better Icons. Database, UI panels and module cubes are
custom procedural geometry. Icon identifiers used as source/reference:
ph:code-bold, ph:git-branch-bold, ph:database-bold, ph:browser-bold,
ph:shield-check-bold, ph:cube-bold.
https://github.com/phosphor-icons/core
Phosphor Icons copyright (c) 2023 Phosphor Icons, MIT licence.
The complete licence is included in PHOSPHOR-LICENSE.txt.

interface.webp refined composition
Custom layered app window with a translucent backing, ivory front panel,
mint orbital preview, capsule button and floating code badge. The badge uses
the same Phosphor code contour and licence listed above.

monitor.webp
Custom procedural 3D monitor with a mint frame, ivory stand and a code-editor
screen texture drawn locally. Decorative TypeScript/React sample, file explorer,
line numbers and syntax colours are part of the original screen illustration.
